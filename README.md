# ✈️ Agencia 404 - Travel Website

**Agencia 404** es un sitio web multipágina de temática turística, desarrollado de manera colaborativa como parte de una actividad práctica de desarrollo frontend de **Generation Mexico**.

El proyecto consistió en **refactorizar un sitio web existente utilizando Bootstrap**, mejorando su estructura, navegación, distribución del contenido y diseño visual.

A partir de los requerimientos del laboratorio, el equipo desarrolló una propuesta enfocada en viajes y destinos turísticos de México, incorporando diferentes componentes de Bootstrap y trabajando de manera colaborativa en la construcción de las distintas secciones del sitio.

---

## 🎯 Objetivo del proyecto

El objetivo principal de la actividad fue poner en práctica el proceso de **refactorización de una interfaz web**, incorporando **Bootstrap** a un proyecto previamente desarrollado con HTML y CSS.

Durante el laboratorio se trabajó en:

- Integración de **Bootstrap mediante CDN**.
- Implementación de una **Navbar** para conectar las diferentes páginas.
- Uso del sistema **Grid de Bootstrap** mediante `container`, `row` y `col`.
- Creación de una interfaz distribuida en diferentes secciones.
- Incorporación de componentes de Bootstrap.
- Desarrollo de un formulario de contacto.
- Definición de una paleta visual de máximo cinco colores.
- Adaptación del sitio a diferentes tamaños de pantalla.
- Organización y colaboración entre los integrantes del equipo.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** — estructura y contenido de las páginas.
- **CSS3** — estilos personalizados e identidad visual.

## 📄 Secciones del sitio

El sitio está compuesto por tres páginas principales:

### 🏠 Inicio

Página principal de **Agencia 404**, donde se presenta la temática del sitio bajo el concepto **"Consejo de Viajeros"**.

Incluye:

- Encabezado principal.
- Barra de navegación.
- Carrusel de imágenes con destinos turísticos de México.
- Distribución del contenido utilizando el Grid de Bootstrap.
- Espacios laterales destinados a futuras secciones de publicidad y noticias.
- Footer con navegación adicional.

### 👥 Quiénes somos

Sección destinada a presentar información relacionada con el equipo y el propósito del sitio.

Mantiene la misma estructura visual y navegación utilizada en las demás páginas del proyecto.

### ✉️ Contacto

Página que incorpora un formulario para que los usuarios puedan ingresar:

- Nombre.
- Correo electrónico.
- Teléfono.
- Comentarios o sugerencias.
- Aceptación de términos y condiciones.

El formulario utiliza componentes y estilos proporcionados por Bootstrap.
